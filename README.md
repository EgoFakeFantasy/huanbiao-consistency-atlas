# 幻标 · 一致性强度图谱

静态网站，直接打开 `index.html` 可用。GitHub Pages 可从仓库根目录发布，无需构建。

内容以[幻标 2.0 原表](https://www.bilibili.com/opus/1023393752074420246)的 tier 名称与顺序为导航，再按相对一致性强度重新组织理论。原表的知乎[方向说明](https://zhuanlan.zhihu.com/p/2086038319830508988)列为参考链接。图中明确区分直接蕴含、相对一致性与跨背景关联；不能把 ZFC 内的大基数链直接接到不采用选择公理的公理上。

每个独立性命题的弹窗附解决者、年份、工作介绍及原始论文 DOI 或原文链接。文献包括 Gödel (1931, 1938)、Cohen (1963)、Shelah (1974, 1984)、Solovay (1970)、Mitchell (1972)、Martin–Steel (1989)、Baumgartner (1984)、Solovay–Tennenbaum (1971)。
